2. Global True Solar Time & Historical DST Calibration (53,000+ Places)

Civil clock time reflects administrative time zones rather than the local meridian crossing of the sun. Across wide time zones—such as China Standard Time (UTC+8, referenced to 120.0°E)—western cities like Chengdu (104.06°E) or Urumqi (87.62°E) lag civil clock time by more than an hour. Our True Solar Time calibration guide and GET /api/cities atlas apply three sequential steps:

  1. Historical IANA Daylight Saving Deduction: Using the IANA ZoneInfo database for the exact birth timestamp and location, any active historical summer-time shift—including PRC Summer Time (1986–1991), South Korean historical DST (1948–1960, 1987–1988), US/EU transitions, and half-hour zones (UTC+5:30, UTC+9:30)—is deducted to recover standard meridian civil time $T_{\text{std}}$.
  2. Longitude Meridian Offset: Earth rotates $1^\circ$ every 4 minutes. Given local east longitude $\lambda$ and zone reference meridian $\lambda_0 = 15^\circ \times \Delta_{\text{UTC}}$: 
    Δt_lon (minutes) = 4.0 × (λ − λ_0)
  3. Solar Equation of Time $E(d)$: Orbital eccentricity and axial obliquity add an seasonal offset between $-14.2$ and $+16.4$ minutes across day-of-year $d$: 
    T_true_solar = T_std + Δt_lon + E(d)

function reduce22(n) {
  while (n > 22) {
    n = String(n).split('').reduce((sum, d) => sum + Number(d), 0);
  }
  return n;
